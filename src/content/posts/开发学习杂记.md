### 良好的项目架构

一个良好的 agent 项目架构：

```
my_agent_project/
├── main.py                  # 入口：只负责启动和交互循环
├── config.py                # 配置：模型名、API key、温度等集中管理
├── agents/
│   └── assistant.py         # agent 的组装逻辑（模型 + 工具 + prompt）
├── tools/                   # 工具层：每个工具一个文件
│   ├── __init__.py          # 统一导出 all_tools
│   ├── get_weather.py
│   └── calculate_expression.py
├── prompts/                 # prompt 较长时，从代码中抽出来单独放
│   └── assistant.py         # 或者直接写成 .txt / .jinja 模板
├── services/                # 外部世界的封装：API 客户端、数据库访问等
│   └── weather_api.py       # 真正的天气 API 请求放这里，tool 只是调用它
└── tests/                   # 测试，目录结构镜像源代码
    └── test_tools/
        └── test_calculate.py
```

1. **入口要薄**：main.py 只做"读输入 → 调 agent → 打印输出"。  
2. **依赖单向流动**：main → agents → tools → services，底层不知道上层的存在，防止出现循环引用
3. **配置集中、密钥走环境变量**：模型名、base_url、温度这类东西收到 config.py 或 .env 里，并且 .env 要加进 .gitignore。

### 良好的 python 命名规范

| 类型 | 风格 | 示例 | 说明 |
|------|------|------|------|
| 变量、函数 | snake_case | `user_input`、`get_weather()` | 全小写，下划线分隔 |
| 类 | PascalCase | `WeatherClient`、`CalculateExpressionInput` | 大驼峰，不用下划线 |
| 常量 | SCREAMING_SNAKE_CASE | `API_BASE_URL`、`MAX_RETRIES` | 全大写 |
| 模块/文件名 | snake_case | `get_weather.py` | 和函数一样 |
| 包/目录名 | 全小写 | `tools/`、`agents/` | 尽量短，尽量不用下划线 |
| 私有成员 | 前缀下划线 | `_internal_helper()` | 表示"别从外部直接用" |

### python 创建虚拟环境

在项目目录下，使用 `python -m venv venv` 可以创建一个虚拟环境。

然后用以下方法激活虚拟环境：

**Windows (PowerShell)：**

```powershell
venv\Scripts\Activate.ps1
```

**Windows (CMD)：**

```cmd
venv\Scripts\activate.bat
```

**Mac/Linux：**

```bash
source venv/bin/activate
```

当命令行前面出现（venv）则激活成功。

然后就可以用 `pip install` 安装依赖包了。

你可以用 `pip freeze > requirements.txt` 导出依赖包，同样，你也可以用 `pip install -r requirements.txt
` 安装清单上的依赖。

### 一些 python 常用包及用法

**@property 修饰**

把类的方法伪装成属性来访问。

```py
class Circle:
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return 3.14 * self.radius ** 2

c = Circle(5)
print(c.area())  # 注意要加括号

#==================================

class Circle:
    def __init__(self, radius):
        self.radius = radius

    @property
    def area(self):
        return 3.14 * self.radius ** 2

c = Circle(5)
print(c.area)    # 不用括号，像读属性一样，实际是调用了方法
```

**dotenv 库**

load_dotenv 来自第三方库 python-dotenv（需要 `pip install python-dotenv`），作用是**把 .env 文件里写的环境变量加载到程序里**，常用来管理密钥、数据库密码等敏感配置。

```py
from dotenv import load_dotenv
import os

load_dotenv()  # 默认读取当前目录下的 .env

db_password = os.getenv("DB_PASSWORD")
api_key = os.environ["API_KEY"]
print(db_password)  # secret123
```

**dataclasses 库**

dataclass 是 Python 标准库 dataclasses 中的一个装饰器，用 @dataclass 装饰 class 后会**自动帮你生成类的常用样板代码**（构造方法 `__init__`、`__repr__`、`__eq__` 等），当定义**以存储数据为主**的类时经常使用。

不使用：

```py
class Point:
    def __init__(self, x: int, y: int):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Point(x={self.x}, y={self.y})"

    def __eq__(self, other):
        if not isinstance(other, Point):
            return NotImplemented
        return self.x == other.x and self.y == other.y
```

使用：

```py
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int
```

**enum 包**

给一组相关的常量起名，避免用散落的裸字符串/数字导致拼写错误、语义不清。

```py
from enum import Enum

class Status(Enum):
    RUNNING = "running"
    STOPPED = "stopped"
    PAUSED = "paused"

def set_status(status):
    if status is Status.RUNNING:
        ...

set_status("Running") # 手动拼写可能会错误
set_status(Status.RUNNING)  # 用 Enum 保证了如果用错值会直接报错
```

常用变体：

```py
from enum import IntEnum, StrEnum  # StrEnum 需 Python 3.11+

class HttpCode(IntEnum):
    OK = 200
    NOT_FOUND = 404

class Direction(StrEnum):
    UP = "up"
    DOWN = "down"

class MessageRole(str, Enum):
    # 混合继承，让成员拥有字符串的行为（进行比较、拼接等）
    USER = "user"
    ASSISTANT = "assistant"
    TOOL = "tool"
    SYSTEM = "system"
```

**typing 包**

typing 是 Python 标准库中的一个模块，专门用于类型提示（Type Hints）。它让你可以在代码中标注变量、函数参数和返回值的预期类型，而不影响程序运行时的行为。

```python
# =============================================================================
# 0. TYPE_CHECKING —— 仅在类型检查时导入，避免循环导入和运行时开销
# =============================================================================
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    # 这些导入只在类型检查阶段存在，运行时不会真正执行
    import datetime  # noqa: F401


# =============================================================================
# 1. 基础容器类型（Python 3.9+ 可直接用内置类型作为泛型，如 list[int]）
#    3.8 及之前需用 typing.List, typing.Dict 等
# =============================================================================
from typing import List, Dict, Tuple, Set  # 旧写法，兼容老版本

def process_data(
    items: list[dict[str, int]],           # 列表，元素为 dict[str, int]
    mapping: dict[str, list[int]],         # 字典，值为列表
    coords: tuple[float, float],           # 固定长度元组：(x, y)
    flags: tuple[int, ...],                # 变长元组，元素都是 int
    tags: set[str],                        # 字符串集合
) -> list[str]:
    """
    展示基础容器类型的用法。
    Python 3.9+ 推荐直接用 list[int]、dict[str, int] 等内置泛型。
    """
    result: list[str] = []
    for tag in tags:
        result.append(tag.upper())
    return result


# =============================================================================
# 2. Union / Optional / 联合类型 —— 表示"可以是 A，也可以是 B"
# =============================================================================
from typing import Union, Optional

def old_style_union(value: Union[int, str]) -> str:
    """旧写法：Union[int, str] 表示 int 或 str"""
    return str(value)

def old_style_optional(query: Optional[str] = None) -> str:
    """旧写法：Optional[str] 等价于 Union[str, None]"""
    return query or "default"

def modern_union(value: int | str) -> str:           # Python 3.10+
    """新写法：X | Y 替代 Union[X, Y]"""
    return str(value)

def modern_optional(query: str | None = None) -> str:  # Python 3.10+
    """新写法：str | None 替代 Optional[str]"""
    return query or "default"


# =============================================================================
# 3. Any —— 任意类型，绕过类型检查（尽量少用）
# =============================================================================
from typing import Any

def log_anything(data: Any) -> None:
    """
    Any 表示接受任何类型，类型检查器不会对 data 做任何推断。
    与 object 不同：Any 允许调用任何方法而不报错（隐式 unsafe）。
    """
    print(f"Logged: {data}")
    # data.any_method()  # 类型检查器不会报错，但运行可能出错


# =============================================================================
# 4. Literal —— 限定只能是某些字面量值
# =============================================================================
from typing import Literal

LogLevel = Literal["debug", "info", "warning", "error"]

def set_log_level(level: LogLevel) -> None:
    """
    参数 level 只能是 "debug", "info", "warning", "error" 之一。
    传入其他字符串会在类型检查阶段报错。
    """
    print(f"Log level set to: {level}")

# 5. Final / ClassVar —— 常量与类变量标注
# =============================================================================
from typing import Final, ClassVar

class AppConfig:
    """
    Final: 标注后不应被重新赋值（类型检查器会警告）
    ClassVar: 标注类变量，表示该属性属于类而非实例
    """
    MAX_CONNECTIONS: Final[int] = 100        # 常量，不应修改
    APP_NAME: Final[str] = "MyApp"

    instance_count: ClassVar[int] = 0       # 类变量，所有实例共享

    def __init__(self, env: str) -> None:
        self.env = env                       # 实例变量，无需 ClassVar
        AppConfig.instance_count += 1

# 6. TypedDict —— 带类型的字典（结构化字典）
# =============================================================================
from typing import TypedDict

class Movie(TypedDict):
    """
    TypedDict 用于描述具有固定键和类型的字典结构。
    比普通 dict 更严格，类型检查器会检查键是否存在、类型是否匹配。
    """
    name: str
    year: int
    rating: float

# 使用方式
def get_movie_info(movie: Movie) -> str:
    return f"{movie['name']} ({movie['year']}): {movie['rating']}/10"

# 7. NamedTuple —— 带类型的具名元组
# =============================================================================
from typing import NamedTuple

class Point(NamedTuple):
    """
    NamedTuple 是 tuple 的子类，但字段有名称和类型。
    比普通 tuple 可读性更好，且不可变。
    """
    x: float
    y: float

def move_point(p: Point, dx: float, dy: float) -> Point:
    return Point(p.x + dx, p.y + dy)

# 8. NewType —— 创建具有语义区分的类型别名
# =============================================================================
from typing import NewType

# 底层都是 int，但类型检查器会将它们视为不同类型
UserId = NewType("UserId", int)
OrderId = NewType("OrderId", int)

def fetch_user(user_id: UserId) -> str:
    return f"User-{user_id}"

def fetch_order(order_id: OrderId) -> str:
    return f"Order-{order_id}"

# 使用
uid = UserId(42)
# fetch_order(uid)  # ❌ 类型错误！UserId 不能传给 OrderId 参数


# =============================================================================
# 9. overload —— 函数重载（根据参数类型返回不同类型）
# =============================================================================
from typing import overload

@overload
def parse_value(value: str) -> int: ...

@overload
def parse_value(value: bytes) -> str: ...

@overload
def parse_value(value: None) -> None: ...

def parse_value(value: str | bytes | None) -> int | str | None:
    """
    实际实现函数，类型检查器会结合 @overload 签名进行精确推断。
    调用者传入 str 时，类型检查器知道返回 int；
    传入 bytes 时，知道返回 str；
    传入 None 时，知道返回 None。
    """
    if value is None:
        return None
    if isinstance(value, bytes):
        return value.decode("utf-8")
    return int(value)

# 10. Annotated —— 给类型附加元数据（供运行时框架读取）
# =============================================================================
from typing import Annotated

class FieldMeta:
    """自定义元数据类"""
    def __init__(self, description: str, min_length: int = 0) -> None:
        self.description = description
        self.min_length = min_length

def create_user(
    name: Annotated[str, FieldMeta("用户名", min_length=2)],
    age: Annotated[int, FieldMeta("年龄", min_length=0)],
) -> dict[str, str | int]:
    """
    Annotated[实际类型, 元数据1, 元数据2, ...]
    类型检查器只看第一个参数（str/int），框架/工具可以读取后面的元数据。
    """
    return {"name": name, "age": age}

# 11. Self —— 返回自身类型的简写（Python 3.11+）
# =============================================================================
from typing import Self  # Python 3.11+

class Builder:
    """
    Self 表示当前类的类型。
    子类继承后，方法返回类型会自动匹配子类，无需重写类型注解。
    """
    def __init__(self) -> None:
        self._parts: list[str] = []

    def add(self, part: str) -> Self:
        self._parts.append(part)
        return self

    def build(self) -> str:
        return "-".join(self._parts)

class AdvancedBuilder(Builder):
    """继承 Builder，add() 的返回类型自动推断为 AdvancedBuilder"""
    def uppercase(self) -> Self:
        self._parts = [p.upper() for p in self._parts]
        return self
```
